# Model checkpoints

The Tiny-Dense checkpoint is hosted in the
[WiFo-2 model repository](https://huggingface.co/pku-pcni-lab/WiFo-2/tree/main/Tiny-dense).

Download `Tiny-dense/model_best.pkl` under this directory and pass its path to
`--file_load_path`. The `.pkl` suffix is optional in the command.
